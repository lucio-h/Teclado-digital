# ⌨️ Keyboard - Teclado Virtual Interativo

Um projeto de teclado virtual interativo desenvolvido com **HTML, CSS e JavaScript**, focado principalmente em manipulação de eventos de teclado e interações em tempo real.

## 🚀 Sobre o projeto

O objetivo desse projeto foi praticar conceitos fundamentais do JavaScript, principalmente relacionados a:

* Eventos de teclado (`keydown` e `keyup`)
* Manipulação do DOM
* Estados de teclas como `Caps Lock` e `Shift`
* Feedback visual em tempo real
* Inserção dinâmica de caracteres
* Responsividade e estilização moderna

O teclado possui integração com o teclado físico do usuário, destacando visualmente as teclas pressionadas enquanto também permite interação totalmente virtual através dos botões na tela.
